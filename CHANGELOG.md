## [2.0.0] - 2026-10-02

Скрипт переписан с нуля: `99-motd` → `motd.sh`. Цель — кроссдистрибутивность
(Gentoo, Debian, Ubuntu, Arch, Alpine и др.) и чистый POSIX `sh`
(bash / dash / busybox-ash).

### Added
- Шапка с описанием скрипта, автором и ссылкой на GitHub.
- Цветные полосы заполнения для памяти и swap (`█`/`░`, ширина 24 символа)
  с цветом по порогам: зелёный < 70%, жёлтый 70–89%, красный ≥ 90%.
- Строка `Logged in` — список уникальных имён вошедших пользователей.
- Определение реального количества физических ядер CPU по `physical id`/`core id`
  из `/proc/cpuinfo` (раньше выводилось число потоков дважды).
- Определение ОС через `/etc/os-release` (`PRETTY_NAME`) с запасным вариантом
  `uname -o`; дополнительно выводятся `/etc/gentoo-release` и `/etc/debian_version`,
  если они есть.
- Получение IP-адресов через `ip -o addr show scope global` с откатом на `hostname -I`.
- Цепочка запасных вариантов для имени хоста: `hostname -f` → `hostname` →
  `/etc/hostname` → `uname -n`.
- Вспомогательные функции `rep` (повтор символа, корректно с UTF-8) и `bar`.

### Changed
- **Несовместимо:** файл переименован из `99-motd` в `motd.sh`.
- **Несовместимо:** изменён формат вывода:
  - строки `Kernel Release` и `Kernel Version` объединены в одну `Kernel` (`uname -r`);
  - `Memory used %` / `Swap used %` → `Memory used` / `Swap used` с полосой и
    целым процентом вместо дробного числа с шестью знаками;
  - `System uptime` → `Uptime` в компактном виде `Nd Nh Nm`;
  - `Users` выводит `N logged on` вместо `Currently N user(s) logged on`;
  - разделитель удлинён до 70 символов.
- Вывод через `printf '%b'` вместо `echo` — одинаковое поведение escape-
  последовательностей во всех оболочках.
- Использование памяти считается как `MemTotal − MemAvailable` из `/proc/meminfo`
  (реально занятая память, без учёта кэша), а не через `free`.
- Количество процессов считается по каталогам `/proc/[0-9]*` вместо `ps aux | wc -l`.
- Количество пользователей берётся из `who` вместо `users`.
- Определение времени суток упрощено, переменные в `test` взяты в кавычки.
- Подстановки команд переведены с обратных кавычек на `$(...)`.

### Removed
- Зависимости от `lsb_release`, `free`, `ps` и `hostname --all-ip-addresses`
  (отсутствуют на части дистрибутивов, например в Alpine/busybox).
- Неиспользуемые цветовые переменные (`tcLtR`, `tcLtP`, `tcLtC`, `tcW`).
- Закомментированный вызов `uname -snrvm`.

### Fixed
- Деление на ноль и ошибка `awk` при отсутствии swap — теперь выводится `0%`.
- `CPU Cores/Threads` показывал число потоков в обоих полях.
- Счётчик процессов был завышен на 1 из-за строки заголовка `ps aux`.
- Ошибки `not found` / `No such file` и неполная строка `OS Release` на системах
  без `lsb_release` или `/etc/debian_version`.
- Лишний пробел в приветствии `Good evening !`.
- Bash-специфичная последовательность `\e[39m`, которая не работала в `dash`.

## [1.0.0] - 2026-05-15

Первая версия — `99-motd` для `/etc/update-motd.d/` (Debian/Ubuntu).

### Added
- Цветной баннер с приветствием по времени суток (morning / afternoon / evening).
- Вывод даты и времени сервера, полного имени хоста и IP-адресов.
- Вывод релиза ОС (`lsb_release`) и версии Debian (`/etc/debian_version`).
- Вывод релиза и версии ядра.
- Вывод количества ядер/потоков CPU.
- Вывод количества вошедших пользователей.
- Вывод нагрузки системы (load average за 1 минуту) и количества процессов.
- Вывод процента использования памяти и swap.
- Вывод времени работы системы в днях, часах и минутах.
